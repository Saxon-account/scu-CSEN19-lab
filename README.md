# scu-CSEN19-lab

Lab projects for CSEN 19 (Data Structures) at Santa Clara University.
All programs are written in C. Each project is stored as a `.tar` file.

## Files

- `count.c` — counts the words in a text file
- `project2.tar` — sets of strings: `unique` and `parity` programs using sorted and unsorted arrays
- `project3.tar` — the same set programs written for strings and for generic data
- `project4.tar` — linked lists, a radix sort, and a maze program
- `project5.tar` — Huffman coding: a priority queue, plus `pack`/`huffman` programs that compress files
- `project6.tar` — the set programs using a hash table
- `looney_lists.tar` — linked list work: list, maze, radix sort, and quicksort programs

Open a project by extracting its tar file, for example `tar -xf project5.tar`.
Each project folder has its own `Makefile`.
